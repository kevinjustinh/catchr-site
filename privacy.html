Catchr Chrome Extension

Privacy Policy

Last updated: May 2026

Catchr is a Chrome extension helping job seekers track applications and refine resumes with AI. This page outlines what data Catchr accesses, how it's used, and what is never collected.

Catchr has no backend server. We do not collect, store, transmit, or have any access to your personal data.

Data we never collect

The extension includes no analytics, tracking pixels, or account requirements. Nothing you do in Catchr is reported back to us.

Data stored locally on your device

The following information is saved in your browser's local storage and never leaves your device:

  • Your Gemini API key
  • Connected resume file(s) — name and ID only, via Google file picker
  • Connected job tracking sheet — name and ID only, via Google file picker

Data sent to third-party services

Catchr connects to Google services using your own credentials:

  • Google Sheets API — logs applications to your personal Sheet
  • Google Docs API — reads your resume and creates tailored copies
  • Google Drive API — organizes tailored copies using the drive.file scope
  • Google Gemini API — processes resume content and job descriptions using your API key

Your Gemini API key is stored locally in your browser's storage and is sent directly to the Gemini API to process requests. It is never transmitted to any Catchr developer servers.

Catchr's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Job page data

Catchr reads job listing pages (title, company, location, description) locally in your browser, or sends the content directly to Gemini using your API key. This data is not saved to any external server or storage outside your own browser and Google account.

Permissions

  • identity — Google OAuth authentication
  • storage — local browser settings
  • activeTab / scripting — reading job listing pages
  • notifications — alerting you when a task completes
  • alarms — background task maintenance
  • webNavigation — detects when you navigate to a job page so the in-site button can appear

Children's privacy

Catchr is intended for adults only and does not knowingly collect information from anyone under 13.

Changes to this policy

If this policy changes materially, the date above will be updated. Continued use of Catchr after changes implies acceptance.
